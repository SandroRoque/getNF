# Spending categories: one tree for every data source (receipts now; card/bank statements etc. later).
# DRAFT 2026-10-08, edit freely. See docs/decisions.md D14.
#
# Format: one node per line, indented by 2 spaces per level. `slug  Label`. `#` starts a comment.
# A node's id is its slug path, e.g. food.produce.fruit. Changing a Label is free; changing or moving a
# slug renames the id, so products assigned to it must be migrated (the loader will refuse to orphan them).
#
# Rules of thumb:
# - Each product gets exactly ONE category, the most specific node that fits. Totals then add up to what was spent.
# - Cross-cutting questions ("ultra-processed", "frozen", "for the coffee ritual") are tags: see tags.txt.
# - Grocery branches are deep because receipts give item-level detail. Other branches stay shallow until a
#   source with that detail shows up.
